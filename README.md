
# SHOWNPIL URL

나만의 URL 단축 및 관리 웹 서비스입니다.

## Overview
사용자가 URL을 단축하고, 계정을 통해 자신의 URL을 관리할 수 있도록 개발하는 프로젝트입니다.

## Features
- 사용자 로그인
- 관리자 및 사용자 페이지 분리
- URL 단축 기능
- 사용자별 URL 관리
- 데이터베이스 연동(SUPA BASE)

## Tech Stack
- HTML
- CSS
- JavaScript
- Node.js
- Express
- Supabase
- PostgreSQL

## Project Structure
- `server/` — 서버 코드
- `admin/` — 관리자 페이지
- `user/` — 사용자 페이지

## Development Status
현재 완성적으로 프로젝트가 완성 되었고 피드백을 통해 개선하는 중입니다.

## Security
- 비밀 키와 환경 변수 파일은 저장소에 포함하지 않습니다.
- 서버 설정은 환경 변수로 관리합니다.
